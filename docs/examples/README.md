# Examples

Real excerpts from the five projects this seed was distilled from, so a new project can see what "good" looked like in practice. Each file says what the project was, which patterns it contributed, and quotes the source. These are reference material: delete this folder from a new project once it is no longer useful (`scripts/init.sh --strip-examples`).

| Project | What it is | What it contributed |
|---|---|---|
| [Battle Drill](battle-drill.md) | Fortnite island (UEFN + Verse) teaching squad tactics | The loop protocol, the verifier ladder, the in-game AutoTest contract, iteration hand-off documents, lessons as rules with corrections |
| [Shockwave Playground](shockwave-playground.md) | Fortnite island, five movement mini-games | Autonomy policy ("never wait idle"), the human queue, robot runs, measurement sessions, a project imported from a sibling project |
| [Timeline Writer](timeline-writer.md) | Local studio app for alternate-history worlds (Python) | AGENTS.md as the entry point, `log.md`, three interlocking loops, worktrees for parallel agents, security checks, cost caps |
| [Tesseract](tesseract.md) | SwiftUI iOS app, Ultimate Tic-Tac-Toe | A pinned one-command verifier, toolchain pre-flight, the visible dev version, a pivot as a confirmed decision record |
| [Aztlan](aztlan.md) | The content vault behind Timeline Writer | Records with frontmatter, stage → commit, Established vs Proposed, decisions as files, provenance per generation |

Source repositories (private): `iturbe/battle-drill`, `iturbe/shockwave-playground`, `iturbe/timeline_writer`, `iturbe/tesseract-v2`, `iturbe/aztlan`.
