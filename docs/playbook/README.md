# Playbook

How the work is done, for any project made from this seed. `AGENTS.md` holds the short, binding rules; these files hold the reasoning, the detail and the examples. Read the one you need, when you need it.

| File | Read it when |
|---|---|
| [LOOP_ENGINEERING.md](LOOP_ENGINEERING.md) | Before any long, multi-step or unattended run |
| [VERIFICATION.md](VERIFICATION.md) | Setting up `scripts/verify.sh`, an in-situ harness, robots, measurement sessions |
| [HUMAN_IN_THE_LOOP.md](HUMAN_IN_THE_LOOP.md) | Writing anything for the owner: queue items, iteration plans, gates, decision rounds |
| [ARCHITECTURE_PATTERNS.md](ARCHITECTURE_PATTERNS.md) | Designing the code structure, or adding generated content |
| [DOCS_DISCIPLINE.md](DOCS_DISCIPLINE.md) | Deciding where a fact goes, or when a doc gets long |
| [PARALLEL_AGENTS.md](PARALLEL_AGENTS.md) | More than one agent or session works on the repo |
| [SECURITY.md](SECURITY.md) | Touching keys, pushing, or anything destructive or paid |
| [MODELS_AND_COSTS.md](MODELS_AND_COSTS.md) | The project calls model or media APIs |
| [RESEARCH_NOTES.md](RESEARCH_NOTES.md) | Revising the seed; the outside sources behind it |

Real examples from the projects this was distilled from are in [`../examples/`](../examples/).
